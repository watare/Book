## Calendrier des trails en France

```
SITES POUR TROUVER TA PREMIÈRE COURSE
══════════════════════════════════════

→ bases-de-trail.fr : Base de données complète
→ runtrail.fr : Calendrier + résultats
→ topchrono.biz : Inscription en ligne
→ livetrail.net : Suivi en direct des courses

CONSEIL : Choisis un trail local de 15-20 km pour commencer.
Ambiance > Performance. L'objectif est de finir, pas de gagner.
```
