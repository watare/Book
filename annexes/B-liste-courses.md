## Recettes express anti-cravings (5 minutes)

```
SNACK URGENCE #1 : Pomme + beurre de cacahuète
  → Couper la pomme. Tremper dans le beurre de cacahuète.
  → Protéines + fibres + bons gras = satiété

SNACK URGENCE #2 : Yaourt grec + noix + miel
  → Yaourt dans un bol. Poignée de noix. Filet de miel.
  → Protéines + probiotiques + bon gras

SNACK URGENCE #3 : Carottes + houmous
  → Ouvrir le houmous. Tremper les carottes.
  → Fibres + protéines végétales

SNACK URGENCE #4 : Chocolat noir + amandes
  → 2 carrés de chocolat noir + 10 amandes
  → Magnésium + antioxydants + bons gras

SNACK URGENCE #5 : Banane + graines de courge
  → Peler. Manger. Poignée de graines.
  → Potassium + zinc + tryptophane (précurseur sérotonine)
```
