## L'entrepreneur en sevrage : un avantage caché

Paradoxe : les personnes qui ont traversé une addiction et s'en sont sorties développent des compétences **directement transférables** à l'entrepreneuriat :

```
COMPÉTENCES ADDICTION → ENTREPRENEURIAT
═══════════════════════════════════════

Compétence sevrage          │  Application business
────────────────────────────┼──────────────────────────
Tolérance à l'inconfort     │  Gérer l'incertitude
Discipline quotidienne      │  Exécution consistante
Gestion des cravings        │  Résister aux distractions
Résilience après rechute    │  Pivoter après un échec
Pensée en systèmes          │  Automatisation des process
Anti-fragilité              │  Croître grâce aux crises
```

## Le framework pour lancer sans procrastiner

La procrastination entrepreneuriale a la même racine que l'addiction : la recherche du confort immédiat. « Je lancerai quand ce sera prêt » = « juste un dernier joint avant d'arrêter ».

```
LE FRAMEWORK "LEAN REBOOT"
══════════════════════════

Inspiré du Lean Startup (Eric Ries) [1] + Mom Test (Rob Fitzpatrick) [2]

       ┌────────────┐
       │   IDÉE     │ ← Tu l'as trouvée en S3
       └──────┬─────┘
              │
              ▼
       ┌────────────┐
       │  PROBLÈME  │ ← Est-ce un VRAI problème ?
       │  VALIDÉ ?  │   Parle à 10 personnes.
       └──────┬─────┘
              │ OUI
              ▼
       ┌────────────┐
       │    MVP     │ ← La version la plus simple
       │  (< 50€)   │   qui résout le problème
       └──────┬─────┘
              │
              ▼
       ┌────────────┐
       │  PREMIERS  │ ← 1 à 5 vrais utilisateurs
       │  CLIENTS   │   (même gratuits au début)
       └──────┬─────┘
              │
              ▼
       ┌────────────┐
       │  ITÉRER    │ ← Améliorer basé sur le feedback
       │  ou PIVOTER│   (pas sur ton imagination)
       └────────────┘

TEMPS TOTAL pour faire un cycle complet : 2-4 semaines
PAS 6 mois de planification silencieuse.
```

## Le Mom Test : valider sans se mentir

> « Les gens mentent par politesse. Tu dois poser des questions auxquelles ils ne PEUVENT pas mentir. »
> — Rob Fitzpatrick [2]

```
BONNES vs MAUVAISES QUESTIONS
═════════════════════════════

✗ "Tu trouves mon idée cool ?"
  → Tout le monde dit oui. Inutile.

✓ "Comment tu gères [problème] aujourd'hui ?"
  → Décrit le comportement réel.

✗ "Tu achèterais ce produit ?"
  → Les intentions ≠ les actions.

✓ "La dernière fois que tu as eu [problème],
   qu'est-ce que tu as fait ?"
  → Révèle la douleur réelle.

✗ "C'est pas trop cher à 29€/mois ?"
  → Personne ne dit "oui c'est trop cher" en face.

✓ "Combien tu dépenses actuellement pour résoudre
   ce problème ?"
  → Révèle le budget réel.
```

## Le planning entrepreneurial frugal

```
MOIS 1 (semaines 3-6 du programme)
══════════════════════════════════
  Semaine 3 : Brainstorm + sélection top 3
  Semaine 4 : Première action + validation problème
  Semaine 5 : Itération + MVP minimal
  Semaine 6 : Premiers utilisateurs/retours

MOIS 2-3 (post-programme)
═════════════════════════
  → MVP fonctionnel
  → 5-10 utilisateurs actifs
  → Premier feedback structuré
  → Décision : continuer, pivoter, ou tuer

MOIS 4-6
════════
  → Si validation : croissance organique
  → Si pas de traction : pivoter ou nouvelle idée
  → Budget max investi : 200€

RÈGLE D'OR FRUGALE :
  ┌─────────────────────────────────────────────┐
  │  NE DÉPENSE PAS D'ARGENT tant que tu n'as  │
  │  pas de PREUVE que des gens veulent ce que  │
  │  tu construis.                              │
  │                                             │
  │  Pas de logo, pas de carte de visite, pas   │
  │  de site premium. Ce sont des excuses pour  │
  │  ne pas parler à des vrais clients.         │
  └─────────────────────────────────────────────┘
```

## Deep Work + IA : ton duo de productivité

```
UTILISER L'IA INTELLIGEMMENT (au lieu de scroller pendant qu'elle code)
═════════════════════════════════════════════════════════════════════

AVANT (mode passif) :
  Toi → donne une tâche à l'IA → scrolle → récupère le résultat

APRÈS (mode actif) :
  Toi → donne une tâche à l'IA → pendant ce temps :
    │
    ├── Dessine l'architecture du prochain feature (papier)
    ├── Écris la spec utilisateur du feature suivant
    ├── Contacte un utilisateur potentiel (email/message)
    ├── Lis un article technique pertinent
    ├── Fais 20 pompes (oui, même au bureau)
    │
    └── Récupère le résultat de l'IA avec un cerveau FRAIS

  Le temps "pendant que l'IA code" n'est plus du temps perdu.
  C'est du temps de RÉFLEXION STRATÉGIQUE.
```
