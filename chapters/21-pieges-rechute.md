# Chapitre 21 — Les 5 Pièges de la Rechute (et Comment les Désamorcer)

---

## La rechute n'est pas un événement. C'est un processus.

La rechute ne commence pas quand tu allumes une cigarette. Elle commence **des jours ou des semaines avant**, par une série de micro-décisions qui érodent ton système.

> « La rechute est un processus, pas un événement. Elle commence bien avant le premier verre — ou la première bouffée. »
> — Terence Gorski, *Staying Sober* (1986) [1]

```
L'ANATOMIE D'UNE RECHUTE
═════════════════════════

Semaine                                          Rechute
parfaite                                            ↓
  │                                                 │
  │  Micro-décision 1: "Je skip la méditation       │
  │   ce matin, j'ai pas le temps"                  │
  │                                                 │
  │  Micro-décision 2: "Je mange un kebab,          │
  │   c'est pas grave"                              │
  │                                                 │
  │  Micro-décision 3: "Je scrolle juste            │
  │   5 minutes"  (→ 45 min)                        │
  │                                                 │
  │  Micro-décision 4: "Je skip le sport,           │
  │   je suis fatigué"                              │
  │                                                 │
  │  Micro-décision 5: "J'ai mérité une clope,      │
  │   juste UNE"                                    │
  │                                                 │
  └─────────────────────────────────────────────────►

CHAQUE MICRO-DÉCISION est un pas vers la rechute.
Le piège est de ne pas les voir comme liées.
```

## PIÈGE 1 : « Juste un(e) »

Le piège le plus classique et le plus dangereux.

```
LE MYTHE DU "JUSTE UN"
═══════════════════════

Ce que tu te dis :
  "J'ai 4 semaines clean. Un seul joint pour fêter ça.
   Je gère maintenant."

Ce qui se passe dans ton cerveau :
  1 joint → réactivation IMMÉDIATE des circuits dormants
       → "C'était bien..."
       → "Un de temps en temps, c'est OK"
       → retour progressif à la consommation régulière
       → en 2-4 semaines = retour au niveau d'avant

Données : 90%+ des fumeurs qui reprennent "juste une cigarette"
redeviennent fumeurs réguliers dans les 12 mois. [2]

  ┌─────────────────────────────────────────────────┐
  │  "JUSTE UN" N'EXISTE PAS.                      │
  │                                                 │
  │  C'est comme dire "je remets juste un doigt     │
  │  dans la prise électrique pour voir".           │
  │  Le circuit est toujours câblé.                 │
  │  Il suffit de le réactiver.                     │
  └─────────────────────────────────────────────────┘

DÉSAMORÇAGE :
  → Quand tu penses "juste un" :
    1. Nomme-le : "C'est le piège #1."
    2. Rappelle-toi : "Il n'y a jamais 'juste un'."
    3. Relis le chapitre 2 (ce que ça fait au cerveau).
    4. Appelle ton accountability partner.
```

## PIÈGE 2 : L'érosion des routines

```
LE GLISSEMENT SILENCIEUX
════════════════════════

Semaine 3 : Tu sautes la méditation une fois.
            "Pas grave, j'étais pressé."

Semaine 4 : Tu sautes le sport deux fois.
            "J'étais fatigué."

Semaine 5 : Tu ne remplis plus le journal.
            "Je sais ce que j'ai à faire."

Semaine 6 : Tu te couches à minuit.
            "Juste ce soir."

Semaine 7 : Tu recommences à scroller 2h.
            Le système est compromis.

  ┌─────────────────────────────────────────────────┐
  │  Les routines ne s'effondrent pas d'un coup.    │
  │  Elles s'érodent UNE DÉCISION À LA FOIS.       │
  │                                                 │
  │  Le signal d'alarme : quand tu commences        │
  │  à te dire "pas grave" plus d'une fois           │
  │  par semaine.                                   │
  └─────────────────────────────────────────────────┘

DÉSAMORÇAGE :
  → La règle "Never Miss Twice" (James Clear)
    Louper une fois = accident. Louper deux fois = pattern.
  → Version mini obligatoire : si tu ne fais pas la routine
    complète, fais la version 6 minutes (chapitre 6).
  → Revue hebdomadaire SACRÉE (dimanche matin) :
    "Combien de routines ai-je sauté cette semaine ?"
```

## PIÈGE 3 : L'excès de confiance

```
LE PIÈGE DE L'HUBRIS
════════════════════

"Ça y est, je suis guéri. Je peux me permettre de..."

C'est souvent entre la semaine 4 et 8 que l'excès de confiance
frappe. Tu te sens tellement bien que tu penses être immunisé.

VÉRITÉ : Les circuits addictifs sont DORMANTS, pas MORTS.
Ils peuvent se réactiver même des années plus tard.

  Confiance saine :
  "J'ai construit un système solide.
   Je continue de l'appliquer."

  Excès de confiance :
  "J'ai plus besoin du système.
   Je gère tout seul maintenant."

DÉSAMORÇAGE :
  → Continue les routines MÊME quand tu te sens bien.
    Surtout quand tu te sens bien.
  → Les athlètes d'élite s'entraînent chaque jour,
    pas parce qu'ils ne savent pas courir,
    mais pour RESTER élite.
  → Tu n'es pas "ex-fumeur". Tu es "non-fumeur actif".
    La nuance est importante.
```

## PIÈGE 4 : Le stress aigu (événement de vie)

```
QUAND LA VIE FRAPPE
═══════════════════

Un conflit au travail. Une rupture. Un problème de santé.
Un échec entrepreneurial. La mort d'un proche.

Ton ancien réflexe : fumer pour "gérer".
Ton cerveau en stress : cortex préfrontal OFFLINE →
système limbique aux commandes → retour aux automatismes.

  Événement stressant ──► Cortex préfrontal débordé
                               │
                               ▼
                    Système limbique : "JE CONNAIS
                    UNE SOLUTION RAPIDE..."
                               │
                               ▼
                    Ancien automatisme : FUMER

DÉSAMORÇAGE :
  → ANTICIPE. Tu sais que le stress viendra.
    Tu ne sais pas quand, mais tu peux planifier ta réponse.
  → Protocole Emergency (chapitre 8) :
    STOP → RESPIRE → VERBALISE → CHRONOMÈTRE → REMPLACE → LOGGE
  → En cas de crise majeure :
    • Appelle ton accountability partner IMMÉDIATEMENT
    • Sors courir (même 10 min)
    • N'affronte JAMAIS un stress aigu seul avec un craving
    • Rappelle-toi : "Fumer ne résout pas le problème.
      Ça ajoute un problème au problème."
```

## PIÈGE 5 : L'alcool (le cheval de Troie)

```
L'ALCOOL : LE FACILITATEUR DE RECHUTE #1
═════════════════════════════════════════

L'alcool désinhibe le cortex préfrontal.
= ton "muscle du non" est anesthésié.
= les cravings passent sans filtre.

  Sobre : Craving → Cortex préfrontal → "Non." → OK
  Alcoolisé : Craving → Cortex préfrontal (KO) → "Oui." → Rechute

Données : L'alcool est impliqué dans 50-70% des rechutes
tabac/cannabis. [3]

STRATÉGIE :
  Pendant les 6 premières semaines :
  → ZÉRO ALCOOL (ou minimum absolu)
  → Pas parce que l'alcool est le problème,
    mais parce qu'il ouvre la porte aux autres problèmes.

  Après les 6 semaines :
  → Consommation modérée et intentionnelle
  → JAMAIS dans un contexte où tu pourrais fumer
  → JAMAIS pour "gérer" une émotion

  ┌─────────────────────────────────────────────────┐
  │  RÈGLE : Si tu bois, tu ne peux pas être        │
  │  dans un environnement où il y a de la weed     │
  │  ou des cigarettes. Point.                      │
  │                                                 │
  │  Les deux ne coexistent pas pendant             │
  │  les 3 premiers mois minimum.                   │
  └─────────────────────────────────────────────────┘
```

## Le protocole post-rechute (si ça arrive)

```
SI TU RECHUTES — PAS DE PANIQUE
════════════════════════════════

CE QUE TU NE FAIS PAS :
  ✗ "C'est foutu, autant continuer"
  ✗ "Je suis nul, je n'y arriverai jamais"
  ✗ "Je recommencerai lundi prochain"
  ✗ Jeter tout le programme à la poubelle

CE QUE TU FAIS :
  ✓ Tu ARRÊTES IMMÉDIATEMENT (pas "je finis le paquet")
  ✓ Tu notes dans ton journal :
    - "Qu'est-ce qui s'est passé ?"
    - "Quel piège m'a eu ?"
    - "Quel maillon de mon système a lâché ?"
    - "Comment je renforce ce maillon ?"
  ✓ Tu appelles ton accountability partner
  ✓ Tu reprends le programme DEMAIN MATIN (pas la semaine prochaine)
  ✓ Tu ne remets PAS les compteurs à zéro de façon punitive
    → "42 jours dont 1 rechute" > "0 jour"

  ┌─────────────────────────────────────────────────┐
  │  UNE RECHUTE N'ANNULE PAS TES PROGRÈS.         │
  │                                                 │
  │  Tes neurones ne se sont pas "dé-recâblés".     │
  │  Ta VO2max n'a pas disparu.                     │
  │  Ton projet n'a pas été effacé.                 │
  │                                                 │
  │  Tu as trébuché. Tu ne t'es pas téléporté       │
  │  au point de départ.                            │
  └─────────────────────────────────────────────────┘
```
