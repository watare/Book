# Chapitre 7 — Méditation & Pleine Conscience : L'Arme Secrète de la Régulation Émotionnelle

---

## Pourquoi la méditation est non-négociable dans un sevrage

Quand tu arrêtes la weed et les clopes, ton cerveau passe par une période de **dérégulation émotionnelle**. Les récepteurs sont en train de se recalibrer. Résultat : irritabilité, anxiété, cravings intenses, insomnies.

La méditation n'est pas un « truc de hippie ». C'est un **entraînement du cortex préfrontal** — la partie de ton cerveau qui dit « non » quand le système limbique crie « FUME MAINTENANT ».

> « La méditation de pleine conscience augmente l'épaisseur du cortex préfrontal et réduit la réactivité de l'amygdale en seulement 8 semaines de pratique régulière. »
> — Hölzel et al., *Psychiatry Research: Neuroimaging*, 2011 [1]

## Les 3 techniques que tu vas utiliser

### Technique 1 : La Respiration 4-7-8 (Dr. Andrew Weil)

**Quand** : matin (routine) + chaque craving + avant le coucher

```
RESPIRATION 4-7-8
═════════════════

    INSPIRE par le nez         RETIENS          EXPIRE par la bouche
         4 secondes           7 secondes             8 secondes

    ┌─────────────┐      ┌─────────────┐      ┌──────────────────┐
    │             │      │             │      │                  │
    │   ████      │      │  ████████   │      │ ████████████████ │
    │   ████      │      │  ████████   │      │                  │
    │   ████      │      │  ████████   │      │                  │
    │             │      │             │      │                  │
    └─────────────┘      └─────────────┘      └──────────────────┘

    Répéter 4 cycles.

    Mécanisme : Active le nerf vague → système parasympathique
    → ↓ cortisol, ↓ rythme cardiaque, ↓ craving

    Temps total : ~1 minute 15 secondes × 4 = ~5 minutes
```

### Technique 2 : Le Body Scan (pleine conscience)

**Quand** : méditation matinale (10 min) + insomnie

```
BODY SCAN — PROTOCOLE
═════════════════════

Position : assis ou allongé, yeux fermés
Durée : 10-20 minutes

Attention dirigée progressivement :

  ┌──── Sommet du crâne
  │
  ├──── Front, yeux, mâchoire (relâcher)
  │
  ├──── Cou, épaules (souvent tendus en sevrage)
  │
  ├──── Bras, mains (jusqu'au bout des doigts)
  │
  ├──── Poitrine (noter la respiration)
  │
  ├──── Ventre (souvent noué → relâcher)
  │
  ├──── Bassin, hanches
  │
  ├──── Cuisses, genoux
  │
  ├──── Mollets, chevilles
  │
  └──── Pieds (jusqu'au bout des orteils)

  Puis : attention sur le corps ENTIER
  Comme un scanner qui descend lentement.

  Règle : PAS de jugement. Observer, ne pas modifier.
  Une pensée arrive ? Note-la. Reviens au corps.
```

### Technique 3 : Le « Urge Surfing » (spécifique addiction)

Développée par le Dr. Alan Marlatt [5], cette technique est **spécifiquement conçue pour gérer les cravings** :

```
URGE SURFING — SURFER SUR LE CRAVING
═════════════════════════════════════

Le craving est comme une vague :

Intensité
   ▲
   │         ╭────╮
   │        ╱      ╲
   │       ╱        ╲
   │      ╱          ╲
   │     ╱     ●      ╲         ● = toi, en train de surfer
   │    ╱    (tu es     ╲
   │   ╱      ici)       ╲
   │  ╱                    ╲
   │ ╱                      ╲──────────
   │╱                              temps passé = craving parti
   └────────────────────────────────────► Temps
   0     5     10    15    20 min

PROTOCOLE :
1. Reconnaître : "Tiens, un craving."
2. Localiser dans le corps : "Où est-ce que je le sens ?"
   (gorge ? poitrine ? mains ? estomac ?)
3. Observer sans juger : "C'est une sensation. Elle monte."
4. Respirer vers la sensation : Inspire vers la zone tendue
5. Accepter : "C'est désagréable mais pas dangereux.
   Ça va passer. Ça passe toujours."
6. Attendre : Le pic du craving dure 10-15 minutes max.
   Après, il redescend.

LA RÈGLE D'OR : Un craving non satisfait DISPARAÎT.
               Un craving satisfait REVIENT plus fort.
```

## Les pièges de la méditation (et comment les éviter)

```
PIÈGE #1 : "J'arrive pas à ne penser à rien"
─────────────────────────────────────────────
Le but n'est PAS de ne penser à rien. Le but est de REMARQUER
que tu penses et de REVENIR à l'ancre (souffle, corps).
Chaque retour = une répétition = un renforcement du cortex préfrontal.
C'est comme une pompe pour le cerveau.

PIÈGE #2 : "Je suis trop agité pour méditer"
─────────────────────────────────────────────
C'est justement QUAND tu es agité que la méditation est
la plus utile. Commence par la 4-7-8. L'activation
parasympathique est mécanique (nerf vague), pas volontaire.

PIÈGE #3 : "J'ai pas le temps"
───────────────────────────────
5 minutes. C'est moins que le temps de rouler un joint.
Tu as le temps.

PIÈGE #4 : "Ça ne marche pas sur moi"
──────────────────────────────────────
Si tu n'avais fait que 3 sessions de musculation dans ta vie
et rien ressenti, tu ne dirais pas "la musculation ne marche pas".
Minimum 2 semaines quotidiennes avant de juger.
```
