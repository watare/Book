## Ce qui se mesure s'améliore

> — W. Edwards Deming

En tant qu'ingénieur, tu sais qu'on ne peut pas optimiser ce qu'on ne mesure pas. Ce chapitre te donne le **dashboard complet** de ton Reboot.

## Le journal : ton outil le plus puissant

Le journaling n'est pas un journal intime. C'est un **outil de debugging** pour ton cerveau.

```
JOURNALING QUOTIDIEN — TEMPLATE (5-7 min)
══════════════════════════════════════════

Date : ___/___/______   Jour #___ du Reboot

MATIN (dans le Reboot Morning) :
  1. Ma priorité #1 aujourd'hui :
     _________________________________________________

  2. Quel trigger vais-je probablement rencontrer ?
     _________________________________________________
     Comment je vais le gérer :
     _________________________________________________

  3. Une chose pour laquelle je suis reconnaissant :
     _________________________________________________

SOIR (avant le coucher, 3 min) :
  4. Score du jour (1-10) : ___

  5. Ai-je fumé ?  □ Non  □ Oui (si oui : pourquoi ?)

  6. Victoire du jour :
     _________________________________________________

  7. Leçon du jour :
     _________________________________________________

  8. Demain, je vais :
     _________________________________________________
```

## Les 3 erreurs de mesure à éviter

```
ERREUR 1 : Mesurer trop de choses
═════════════════════════════════
5-8 KPIs suffisent. Plus = paralysie d'analyse.
Choisis les métriques qui comptent VRAIMENT pour toi.

ERREUR 2 : Se comparer aux autres
═════════════════════════════════
Ton seul benchmark = toi hier.
"Est-ce que je suis meilleur que la semaine dernière ?"
Oui → Continue. Non → Ajuste.

ERREUR 3 : Abandonner la mesure
═══════════════════════════════
"Je sais comment ça va" = le début de l'érosion.
Continue de mesurer même quand tout va bien.
Le pilote automatique a besoin d'instruments.
```
