# Chapitre 9 — Nutrition : Le Carburant du Reboot

---

## Pourquoi la bouffe change TOUT en sevrage

Tu peux avoir la meilleure routine matinale et le système de discipline le plus solide — si tu manges de la merde, ton cerveau ne suit pas. Et pendant un sevrage, la nutrition devient **critique** pour trois raisons :

1. **Tes niveaux de dopamine sont au plancher** → tu as besoin des précurseurs alimentaires
2. **Tes cravings de sucre explosent** → le cerveau cherche un substitut rapide
3. **Ton gut-brain axis (axe intestin-cerveau) est perturbé** → inflammation, humeur instable

> « L'intestin produit 95% de la sérotonine du corps et 50% de la dopamine. Ce que tu manges affecte directement ta chimie cérébrale. »
> — Dr. Emeran Mayer, *The Mind-Gut Connection* (2016) [1]

```

         CERVEAU

           │ ▼
         INTESTIN
```

### Règle 2 : Zéro sucre rapide (les 3 premières semaines minimum)

Le sucre active **les mêmes circuits de récompense** que les drogues [3]. Pendant le sevrage, le sucre est ton pire ennemi — il entretient l'addiction à la dopamine rapide.

```
LE PIÈGE DU SUCRE EN SEVRAGE
═════════════════════════════

Arrêt THC/Nicotine ──► Dopamine de base ↓↓↓
         │
         ▼
Cerveau cherche un substitut ──► SUCRE (dopamine rapide)
         │
         ▼
Pics glycémiques ──► Crashs ──► Envie de fumer/fumer
         │                       (pour compenser le crash)
         ▼
Cercle vicieux
inflammation + fatigue + cravings


SOLUTION : STABILITÉ GLYCÉMIQUE
════════════════════════════════

Glycémie
  ▲
  │
  │  ╭╮    ╭╮    ╭╮          ← Sucre rapide : montagnes russes
  │ ╱  ╲  ╱  ╲  ╱  ╲
  │╱    ╲╱    ╲╱    ╲
  ├─────────────────────── ← Niveau optimal
  │
  │ ──────────────────────── ← Protéines + fibres + bons gras :
  │                             stable, constant
  │
  └──────────────────────────► Temps
```

**À ÉVITER** :
- Sodas, jus de fruits industriels
- Pain blanc, pâtes blanches, riz blanc
- Gâteaux, biscuits, viennoiseries
- Barres céréales industrielles (souvent pires qu'un Mars)
- Céréales du petit-déjeuner (bombe de sucre)

**À PRIVILÉGIER** :
- Fruits entiers (les fibres ralentissent l'absorption)
- Céréales complètes (riz complet, quinoa, avoine)
- Légumineuses (lentilles, pois chiches, haricots)

### Règle 3 : Bons gras pour le cerveau

Ton cerveau est composé à **60% de lipides**. Il a besoin de bons gras pour se réparer.

```

    maquereau                        industriel
  → Noix, graines de lin
  → Huile de colza               Oméga-6 en excès
                                    → Huile de tournesol,
Monoinsaturés                        maïs, soja
  → Huile d'olive, avocat,
    amandes                       Saturés en excès
                                    → Charcuterie, fromage
                                     industriel, fast food

RATIO OPTIMAL OMÉGA-6/OMÉGA-3 : 4:1 maximum
Ratio moyen français : 15:1 → inflammation chronique [4]
```

### Règle 4 : Soigner le microbiote

Le microbiote intestinal est ravagé par le tabac, le cannabis et la malbouffe [5]. Le reconstruire accélère la récupération émotionnelle.

```
ALIMENTS PRO-MICROBIOTE
════════════════════════

PRÉBIOTIQUES (nourrissent les bonnes bactéries)
  → Ail, oignon, poireau, artichaut
  → Banane (pas trop mûre), asperges
  → Avoine, lentilles

PROBIOTIQUES (apportent des bonnes bactéries)
  → Yaourt nature (pas sucré)
  → Kéfir, kombucha
  → Choucroute crue, kimchi
  → Miso

ANTI-INFLAMMATOIRES
  → Curcuma + poivre noir (absorption ×2000)
  → Gingembre
  → Baies (myrtilles, framboises)
  → Thé vert (EGCG + L-théanine = calme + focus)
```

## Le Meal Plan Anti-Cravings (semaine type)

```
PETIT-DÉJEUNER ANTI-CRAVING (choisir 1 par jour)
══════════════════════════════════════════════════

Option A : "L'Ingénieur"
  3 œufs brouillés + avocat + pain complet au levain
  + poignée de noix + thé vert

Option B : "Le Traileur"
  Porridge d'avoine + graines de courge + myrtilles
  + beurre de cacahuète (sans sucre ajouté) + banane

Option C : "Le Rapide"
  Yaourt grec nature + granola maison (flocons d'avoine,
  noix, graines, miel cru) + kiwi

Option D : "Le Smoothie"
  Banane + épinards + beurre d'amande + protéine whey
  + lait d'avoine + graines de chia

→ Tous contiennent : protéines + bons gras + fibres
→ Aucun ne contient : sucre raffiné
```

```
  → Saumon + brocoli + patate douce
```

```
DÎNER (principes)
═════════════════

Plus léger que le déjeuner. Plus de légumes, moins de glucides.
Manger AU MOINS 2h avant le coucher (sommeil profond).

Exemples :
  → Soupe de légumes maison + œuf dur + pain complet
  → Poisson blanc + haricots verts + huile de colza
  → Omelette aux légumes + salade

INTERDIT LE SOIR :
  ✗ Sucre (perturbe le sommeil)
  ✗ Alcool (perturbe le REM)
  ✗ Café/thé après 14h (demi-vie caféine = 6h)
  ✗ Repas trop copieux (digestion → sommeil léger)
```

```
SNACKS ANTI-CRAVINGS (quand le craving frappe)
═══════════════════════════════════════════════

Au lieu de fumer ou grignoter du sucre :

  → Poignée de noix mélangées (amandes, noix de cajou, noisettes)
  → Carré de chocolat noir >85% (magnésium + théobromine)
  → Pomme + beurre de cacahuète
  → Carottes + houmous
  → Thé vert ou tisane (camomille le soir)

  ┌─────────────────────────────────────────────┐
  │  ASTUCE : Prépare tes snacks le dimanche.   │
  │  Des petits sachets prêts dans le frigo.    │
  │  Quand le craving arrive, le snack sain     │
  │  est plus facile que le trajet au            │
  │  distributeur ou au bureau de tabac.         │
  └─────────────────────────────────────────────┘
```

## L'hydratation (le facteur oublié)

```
PROTOCOLE HYDRATATION
═════════════════════

Objectif : 2,5 à 3 litres / jour (plus si sport)

Réveil    : 500ml d'eau (avant toute autre chose)
Matin     : 500ml (thé vert inclus)
Midi      : 500ml
Après-midi: 500ml
Sport     : 500ml-1L (selon durée et chaleur)
Soir      : 500ml (arrêter 1h avant coucher)

POURQUOI C'EST IMPORTANT EN SEVRAGE :
  → Le THC est liposoluble : l'eau aide à l'éliminer
  → La nicotine est hydrosoluble : l'eau accélère le sevrage
  → La déshydratation = fatigue, maux de tête, irritabilité
    (symptômes confondus avec le sevrage)
```
