## Le problème spécifique : l'attente devant l'écran

Tu l'as identifié toi-même : le moment le plus dangereux de ta journée de travail n'est pas la pause café — c'est **quand l'IA code et que tu n'as rien à faire de tes mains et de ton cerveau**.

C'est un trigger moderne, propre à notre époque, et peu de livres en parlent.

## L'usage actif de l'IA (ton cerveau reste allumé)

```
PASSIF vs ACTIF : COMMENT UTILISER L'IA
════════════════════════════════════════

MODE PASSIF (avant) :
  "Écris-moi cette fonction"
  → Attend → Scrolle → Copie-colle → Suivant
  → Ton cerveau : éteint
  → Résultat : tu ne comprends pas ton propre code

MODE ACTIF (après) :
  "Écris-moi cette fonction"
  → PENDANT L'ATTENTE :
    • Écris toi-même le pseudo-code sur papier
    • Dessine l'architecture du module
    • Prépare les tests que tu vas écrire
    • Note les edge cases à vérifier
  → QUAND L'IA RÉPOND :
    • Compare avec ton pseudo-code
    • Review critique (pas de copie-colle aveugle)
    • Identifie ce que tu aurais fait différemment
    • Comprends POURQUOI chaque choix a été fait

  ┌─────────────────────────────────────────────────┐
  │  L'IA est un OUTIL, pas un REMPLAÇANT.          │
  │                                                 │
  │  Un chirurgien utilise des robots assistés.     │
  │  Il ne dort pas pendant l'opération.            │
  │                                                 │
  │  Ton cerveau doit rester aux commandes.         │
  │  L'IA exécute. Toi, tu penses.                 │
  └─────────────────────────────────────────────────┘
```

## Le principe « cerveau allumé »

```
LA RÈGLE DU CERVEAU ALLUMÉ
═══════════════════════════

À tout moment de la journée, ton cerveau est dans 1 de 3 modes :

MODE 1 : CRÉATION (tu produis quelque chose)
  → Code, écriture, design, conversation active, sport
  → Dopamine lente, satisfaction durable

MODE 2 : RÉCUPÉRATION (tu te reposes intentionnellement)
  → Méditation, sieste, marche en nature, stretching
  → Restauration des ressources cognitives

MODE 3 : CONSOMMATION PASSIVE (tu absorbes sans but)
  → Scroll, vidéos random, attente passive
  → Dopamine rapide, vide ensuite

OBJECTIF : Maximiser MODE 1 et MODE 2.
           Éliminer MODE 3.

Le temps "pendant que l'IA code" n'est PAS du mode 3.
C'est du MODE 1 (penser, planifier, sketcher)
ou du MODE 2 (respirer, bouger, se reposer).

JAMAIS du MODE 3.
```
