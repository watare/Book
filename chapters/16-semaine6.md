## Frugalité : le système définitif

```
RÈGLES DE FRUGALITÉ INTELLIGENTE
═════════════════════════════════

RÈGLE 1 : La règle des 48h
  Avant tout achat non-essentiel > 30€, attends 48h.
  Si tu en veux encore après 48h → achète.
  80% du temps, l'envie passe.

RÈGLE 2 : Le coût par utilisation
  Prix / nombre d'utilisations = coût réel
  Chaussures trail à 150€ utilisées 200× = 0,75€/utilisation ✓
  Gadget à 50€ utilisé 2× = 25€/utilisation ✗

RÈGLE 3 : Investir > Dépenser
  Chaque euro va dans 1 des 3 catégories :
  • Besoin (loyer, nourriture) = nécessaire
  • Investissement (livres, sport, business) = croissance
  • Consommation (loisirs, sorties) = plaisir
  → Maximise l'investissement. Minimise la consommation.

RÈGLE 4 : L'automatisation
  Dès que le salaire tombe :
  → Virement auto vers épargne (10%+)
  → Virement auto vers compte "trail/projet" (5-10%)
  → Le reste = budget opérationnel

CALCUL D'ÉCONOMIE ANNUELLE :
┌─────────────────────────────────────────────────┐
│ Clopes arrêtées      : ~250€/mois = 3 000€/an  │
│ Weed arrêtée         : ~150€/mois = 1 800€/an  │
│ Sorties/fast food ↓  : ~100€/mois = 1 200€/an  │
│ Achats impulsifs ↓   : ~100€/mois = 1 200€/an  │
│ ────────────────────────────────────────────     │
│ TOTAL ÉCONOMISÉ      : ~600€/mois = 7 200€/AN  │
│                                                 │
│ En 2 ans = 14 400€ = le capital pour lancer     │
│ ton projet OU courir l'UTMB + tour du monde     │
│ des trails.                                     │
└─────────────────────────────────────────────────┘
```
