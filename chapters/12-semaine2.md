# Chapitre 12 — Semaine 2 : L'Ancrage (Routines & Résistance)

## L'objectif de la semaine

**Transformer la survie en routine. Ancrer les nouvelles habitudes.**

Le pire du sevrage physique est passé. Maintenant, le combat est **psychologique**. C'est la semaine où les petites voix commencent : « Un seul joint pour fêter la semaine 1... », « Une clope ne va pas me tuer... ».

Non. Pas un. Le cerveau te ment. C'est la dopamine qui négocie.

## Focus spécial : le Time-Boxing

Cette semaine, tu commences à **structurer tes journées en blocs**. Plus de journées fluides où le temps t'échappe.

```
COMMENT IMPLÉMENTER LE TIME-BOXING
═══════════════════════════════════

1. Chaque soir (pendant la routine du soir), planifie le lendemain
2. Chaque bloc = une intention claire
3. Les pauses sont planifiées (ET ont une activité prédéfinie)

Outil recommandé :
  → Agenda papier (pas d'app → moins de tentation d'écran)
  → Ou Google Calendar avec des blocs colorés

RÈGLE : Si un bloc est "attente IA" ou "pause",
        il a une activité de remplacement ÉCRITE.

Exemple :
  ┌──────────────────────────────────────────┐
  │ 14:00-14:30 │ DEEP WORK : Feature X     │
  │ 14:30-14:35 │ Si IA code → 20 pompes    │
  │             │ + lire 3 pages             │
  │ 14:35-15:00 │ DEEP WORK : Review code    │
  └──────────────────────────────────────────┘
```

## Les cravings de semaine 2 : différents de S1

```
ÉVOLUTION DES CRAVINGS
═══════════════════════

SEMAINE 1 : Cravings PHYSIQUES (le corps réclame)
  → Fréquents, intenses, prévisibles (toutes les 2-4h)
  → Gérables avec urge surfing + activité physique

SEMAINE 2 : Cravings PSYCHOLOGIQUES (le mental négocie)
  → Moins fréquents mais plus insidieux
  → Prennent la forme de "raisonnements" :
    "Juste un..."
    "J'ai bien mérité..."
    "C'est pas si grave..."
    "Je gère maintenant..."

         ┌─────────────────────────────────────┐
         │  RÈGLE : Si ton cerveau commence    │
         │  à RAISONNER pourquoi tu devrais    │
         │  fumer, c'est un CRAVING DÉGUISÉ.   │
         │                                     │
         │  Un non-fumeur ne raisonne pas      │
         │  sur le fait de fumer.              │
         │  Il n'y pense tout simplement pas.  │
         └─────────────────────────────────────┘

RÉPONSE aux cravings S2 :
  1. Reconnaître : "Tiens, mon cerveau négocie."
  2. Nommer : "C'est la dopamine, pas moi."
  3. Rappeler : "Si je fume, je remets les compteurs à zéro."
  4. Agir : Activité de remplacement (pas de débat interne)
```

## Focus spécial : réduire les écrans

```
PROTOCOLE RÉDUCTION ÉCRANS — SEMAINE 2
═══════════════════════════════════════

ÉTAPE 1 : MESURER
  → Note ton temps d'écran actuel (utilise Screen Time / Digital Wellbeing)
  → Objectif S2 : réduire de 50%

ÉTAPE 2 : ÉLIMINER
  → Supprimer les apps les plus chronophages (TikTok, Reddit, etc.)
  → Désactiver TOUTES les notifications sauf appels et messages directs
  → Retirer les raccourcis des apps sociales de l'écran d'accueil

ÉTAPE 3 : BLOQUER
  → Installer un bloqueur (Freedom, Cold Turkey, ou One Sec)
  → Bloquer pendant les heures de travail : 8h-12h et 13h-17h
  → Bloquer le soir : 21h-7h

ÉTAPE 4 : REMPLACER
  → Un livre physique sur ta table de nuit (pas le téléphone)
  → Un carnet à côté de l'ordinateur (pour les attentes IA)
  → Un podcast en marchant (au lieu de scroller en canapé)
```
