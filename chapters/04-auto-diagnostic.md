# Chapitre 4 — Auto-diagnostic : Cartographie de tes Triggers et Patterns

---

## Avant de changer, mesure.

Un ingénieur ne corrige pas un bug sans d'abord le reproduire et comprendre ses conditions d'apparition. Tes addictions fonctionnent pareil : elles ont des **triggers** (déclencheurs), des **patterns** (schémas répétitifs) et des **contextes** (environnements favorisants).

Ce chapitre est un exercice pratique. Prends un carnet ou ouvre un fichier. Tu vas cartographier ton « code source » comportemental.

---

## Exercice 2 : La Boucle d'Habitude (analyse de pattern)

Charles Duhigg dans *The Power of Habit* (2012) [2] décrit chaque habitude comme une boucle en 3 parties. James Clear dans *Atomic Habits* (2018) [3] l'a étendue à 4 parties. Utilisons le modèle à 4 parties :

```
LA BOUCLE D'HABITUDE (James Clear)
═══════════════════════════════════

    ┌──────────────────────────────────────────────┐
    │                                              │
    │         1. SIGNAL (Cue)                      │
    │         "Qu'est-ce qui déclenche ?"          │
    │                │                             │
    │                ▼                             │
    │         2. ENVIE (Craving)                   │
    │         "Qu'est-ce que je désire vraiment ?" │
    │                │                             │
    │                ▼                             │
    │         3. RÉPONSE (Response)                │
    │         "Qu'est-ce que je fais ?"            │
    │                │                             │
    │                ▼                             │
    │         4. RÉCOMPENSE (Reward)               │
    │         "Qu'est-ce que j'obtiens ?"          │
    │                │                             │
    │                └──────────► Retour au 1.     │
    │                                              │
    └──────────────────────────────────────────────┘
```

### Exemple concret : le dimanche soir chez le voisin

```
ANALYSE DE PATTERN : DIMANCHE SOIR
═══════════════════════════════════

1. SIGNAL     : Dimanche soir, chez le voisin, il sort le matos
2. ENVIE      : Connexion sociale + détente + habitude partagée
3. RÉPONSE    : Tu fumes un joint avec lui
4. RÉCOMPENSE : Moment de convivialité + relaxation + appartenance

         ┌─────────────────────────────────────────┐
         │  Le besoin RÉEL n'est pas la weed.      │
         │  C'est la CONNEXION et la DÉTENTE.      │
         │                                         │
         │  La weed est juste le véhicule actuel.  │
         │  On va trouver un meilleur véhicule.    │
         └─────────────────────────────────────────┘
```

## Exercice 4 : La Cartographie Temporelle

Trace une journée type et identifie les moments de vulnérabilité :

```
CARTOGRAPHIE D'UNE JOURNÉE TYPE
════════════════════════════════

06:00 ░░░░░░░░ Réveil
07:00 ░░░░░░░░ Matin
08:00 ████████ Travail ──────────────── Café + clope ?
09:00 ████████ Travail
10:00 ████████ Pause ──────────────────  ⚠ TRIGGER : pause clope
11:00 ████████ Travail
12:00 ▓▓▓▓▓▓▓▓ Déjeuner ─────────────── ⚠ TRIGGER : clope après repas
13:00 ████████ Travail
14:00 ████████ Travail
15:00 ████████ Pause ──────────────────  ⚠ TRIGGER : baisse énergie
16:00 ████████ Travail
17:00 ████████ Fin journée
18:00 ▓▓▓▓▓▓▓▓ Temps libre ──────────── ⚠ TRIGGER : ennui, écrans
19:00 ▓▓▓▓▓▓▓▓ Dîner
20:00 ░░░░░░░░ Soirée ────────────────── ⚠ TRIGGER : joint détente
21:00 ░░░░░░░░ Soirée                    ⚠ TRIGGER : scroll nocturne
22:00 ░░░░░░░░ Coucher

░ = temps personnel  █ = travail  ▓ = transition
⚠ = moment de vulnérabilité
```

### À faire : trace TA journée

Note pendant 3 jours (avant de commencer le programme) chaque fois que tu :
- Fumes (quoi, quand, où, avec qui, émotion)
- Scrolles passivement (combien de temps, qu'est-ce qui a déclenché)
- Résistes à une envie (bravo — note-le aussi)

## Exercice 5 : Le « Pourquoi » en 5 niveaux

La technique des « 5 Pourquoi » de Toyota fonctionne aussi pour les habitudes :

```
EXEMPLE : 5 POURQUOI
═════════════════════

Pourquoi je fume chez le voisin ?
  → Parce que tout le monde fume.
Pourquoi je ne dis pas non ?
  → Parce que j'ai peur d'être exclu.
Pourquoi j'ai peur d'être exclu ?
  → Parce que c'est mon principal lien social du week-end.
Pourquoi c'est mon principal lien social ?
  → Parce que je n'ai pas investi dans d'autres activités sociales.
Pourquoi ?
  → Parce que fumer était le moyen facile de socialiser.

         ┌─────────────────────────────────────────┐
         │  CAUSE RACINE : Manque d'activités      │
         │  sociales alternatives.                 │
         │                                         │
         │  SOLUTION : Créer des contextes sociaux │
         │  sans substance (trail en groupe,       │
         │  meetups entrepreneurs, etc.)            │
         └─────────────────────────────────────────┘
```
