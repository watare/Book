# Chapitre 20 — Le Dimanche Soir : Socialiser Sans Rechuter

---

## Le cas spécifique qui résume tout

Chaque dimanche soir, tu vas chez ton voisin. C'est un moment que tu apprécies — la convivialité, la décompression, le lien humain. Le problème : jusqu'ici, ce moment incluait systématiquement un joint.

Ce chapitre est un **protocole complet** pour transformer ce rendez-vous sans le supprimer. Parce que s'isoler n'est pas une solution — c'est un autre problème.

---

## Pourquoi ne pas simplement arrêter d'y aller ?

```
L'ISOLEMENT EST PIRE QUE LE TRIGGER
════════════════════════════════════

L'isolement social est un facteur de rechute MAJEUR [1].

  Isolement → Solitude → Ennui → Craving → Rechute

Le but n'est pas d'éviter les gens.
Le but est de changer TON COMPORTEMENT dans le contexte social.

  ┌─────────────────────────────────────────────────┐
  │  Tu ne changes pas ta vie sociale.              │
  │  Tu changes ce que tu fais DANS ta vie sociale. │
  └─────────────────────────────────────────────────┘
```

## Le protocole « Dimanche Soir » — en détail

### Phase 1 : La conversation préalable (une seule fois)

```
PARLER AU VOISIN — SCRIPT SUGGÉRÉ
══════════════════════════════════

"Hey [prénom], je voulais te dire un truc.
J'ai décidé d'arrêter de fumer — la weed et les clopes.
C'est un choix perso, j'ai pas de jugement sur ce que
tu fais toi. Mais je te demande un service :
ne m'en propose pas pendant les prochaines semaines.
Je viendrai toujours le dimanche, j'ai juste besoin
que tu respectes ça."

POURQUOI C'EST IMPORTANT :
  → Tu pose une limite claire (pas d'ambiguïté)
  → Tu dédramatises (pas de jugement)
  → Tu maintiens la relation
  → Tu crées un "contrat social" qui t'aide à tenir

RÉACTIONS POSSIBLES :
  "Ah ouais, respect !" → Super. Le plus probable.
  "Comme tu veux, mais tu vas pas tenir" → Utilise comme fuel.
  "C'est chiant si tu fumes pas" → Réfléchis à la qualité
    de cette amitié. Un vrai ami respecte ta décision.
```

### Phase 2 : La préparation (chaque dimanche)

```
CHECKLIST PRÉ-DIMANCHE SOIR
════════════════════════════

2H AVANT :
  □ Méditation 10 min (urge surfing préventif)
  □ Sport dans la journée (endorphines = protection)

1H AVANT :
  □ Dîner complet et nutritif (estomac plein = moins de cravings)
  □ Préparer ta boisson :
    ┌──────────────────────────────────────────┐
    │ OPTIONS (avoir TOUJOURS quelque chose     │
    │ dans les mains) :                         │
    │                                          │
    │ → Bière sans alcool (Tourtel, Brewdog AF) │
    │ → Thé glacé maison (en thermos)          │
    │ → Perrier / San Pellegrino + citron       │
    │ → Kombucha                                │
    │ → Infusion froide                         │
    └──────────────────────────────────────────┘

15 MIN AVANT :
  □ Relire ton "pourquoi" dans le journal
  □ Envoyer un message à ton accountability partner :
    "Je vais chez le voisin. Je tiens."
  □ Définir une heure de départ (ex: 23h30 max)
  □ Préparer un sujet de conversation non lié au fumage
```

## L'évolution au fil des semaines

```
PROGRESSION DU DIMANCHE SOIR
═════════════════════════════

SEMAINE 1 : Survie
  → C'est nouveau, c'est dur, tu résistes activement
  → Craving : 8-9/10
  → Tu pars peut-être plus tôt que d'habitude
  → C'EST NORMAL ET C'EST OK.

SEMAINE 2 : Adaptation
  → Tu sais ce qui t'attend
  → Craving : 6-7/10
  → Tu commences à trouver un nouveau rythme

SEMAINE 3 : Normalisation
  → Le voisin s'est habitué
  → Craving : 4-5/10
  → Tu commences à apprécier la soirée AUTREMENT
  → Conversations plus profondes (tu es plus présent)

SEMAINE 4 : Transformation
  → Craving : 2-3/10
  → Tu remarques que tu te souviens de la soirée
    (mémoire non altérée par le THC)
  → Peut-être que le voisin commence à poser des questions
    sur ton changement

SEMAINE 5-6 : Nouveau normal
  → Craving : 1-2/10 (occasionnel)
  → Le dimanche soir est redevenu un moment social,
    pas un moment d'addiction
  → Tu es la preuve vivante qu'on peut être cool
    sans fumer
```

## Que faire si le voisin ne respecte pas

```
SCÉNARIOS DIFFICILES ET RÉPONSES
════════════════════════════════

"Allez, juste une taffe, ça va pas te tuer"
→ "Non merci. Vraiment. Respecte ça."
→ Si insistance : "Si t'es pas capable de respecter
   ma décision, je rentre." (et rentre.)

Il sort le matos devant toi exprès
→ "Je vais aux toilettes" / "Je prends l'air"
→ Si c'est systématique : réévalue cette amitié.

La pression du groupe (autres personnes présentes)
→ "Non merci, je suis en mode reboot."
→ Tu n'as PAS à te justifier. "Non" est une phrase complète.

Tu rechutes un dimanche soir
→ Pas de panique. Pas de culpabilité excessive.
→ Journal IMMÉDIAT : "Qu'est-ce qui s'est passé ?"
→ Analyse : quel maillon a lâché ?
→ Lundi matin : le système reprend. Pas "lundi prochain".
   DEMAIN MATIN.
```

## Créer des contextes sociaux alternatifs

```
IDÉES POUR ENRICHIR TA VIE SOCIALE SANS SUBSTANCES
═══════════════════════════════════════════════════

SPORT
  → Rejoindre un groupe de trail du dimanche matin
  → Salle d'escalade avec un ami
  → Football, basket, n'importe quel sport collectif

INTELLECTUEL
  → Club de lecture
  → Meetup tech / entrepreneuriat
  → Hackerspace / fablab local

CRÉATIF
  → Cours de cuisine
  → Atelier bricolage
  → Jeux de société (soirées jeux sans alcool)

NATURE
  → Randonnée groupe le week-end
  → Bivouac (trail de nuit + camping)
  → Bénévolat environnemental

→ L'objectif n'est pas de remplacer le voisin.
  C'est de ne plus dépendre d'UN SEUL contexte social.
```
