## Le Deep Work : ta superpuissance retrouvée

Ton cortex préfrontal est en pleine renaissance. Les 4 semaines sans THC lui ont redonné sa capacité de concentration soutenue. C'est le moment de l'exploiter.

> « Le deep work est la capacité de se concentrer sans distraction sur une tâche cognitivement exigeante. C'est une compétence qui te permet de maîtriser rapidement des choses compliquées et de produire un travail de meilleure qualité, plus vite. »
> — Cal Newport, *Deep Work* (2016) [1]

```
TON PROTOCOLE DEEP WORK
════════════════════════

AVANT la session :
  □ Téléphone en mode avion dans une autre pièce
  □ Bloqueur d'apps activé
  □ Eau + thé à portée de main
  □ Objectif de la session écrit sur un post-it
  □ Timer lancé (90 min max par bloc)

PENDANT :
  □ UNE tâche. Pas de multitasking. Jamais.
  □ Si une idée surgit : note rapide sur papier → retour au travail
  □ Si l'IA code pour toi : bascule sur le "menu de remplacement"
    (pompes, lecture, sketch business — PAS de scroll)

APRÈS :
  □ Note : "Qu'est-ce que j'ai accompli dans ce bloc ?"
  □ Pause vraie (5-10 min, mouvement, pas d'écran)

PLANNING DEEP WORK — SEMAINE 4 :
  Bloc 1 : 07:15-08:45 (après routine matinale)
  Bloc 2 : 09:45-11:15
  Bloc 3 : 14:00-15:30 (ou projet perso)
  = 4h30 de deep work / jour (vs ~1h avant le programme)
```

## Le lancement entrepreneurial

Tu as fait ton brainstorm en S3. Cette semaine, on passe à l'action — mais de manière frugale et intelligente.

```
PROTOCOLE "PREMIÈRE ACTION" — CETTE SEMAINE
════════════════════════════════════════════

ÉTAPE 1 : Choisis UNE idée de ton top 3
  Critère : celle qui t'excite le plus ET qui est la plus
  simple à tester.

ÉTAPE 2 : Définis le MVP (Minimum Viable Product)
  ┌─────────────────────────────────────────────────┐
  │  MVP = la version la plus simple qui permet     │
  │  de vérifier si le problème existe vraiment     │
  │  et si des gens sont prêts à payer pour         │
  │  la solution.                                   │
  │                                                 │
  │  PAS de site web. PAS de logo. PAS de nom       │
  │  de domaine.                                    │
  │                                                 │
  │  Juste : une solution + un premier utilisateur. │
  └─────────────────────────────────────────────────┘

ÉTAPE 3 : La règle des 48h
  Quelle est la première action concrète que tu peux
  faire dans les 48 prochaines heures ?

  Exemples :
  → Appeler 3 personnes qui auraient ce problème
  → Créer un Google Form de 5 questions
  → Écrire un post LinkedIn décrivant le problème
  → Coder un prototype en 4h
  → Faire une landing page simple (Carrd.co = gratuit)

ÉTAPE 4 : FAIS-LE.
  Pas demain. Pas quand ce sera parfait. Maintenant.
  Imparfait > inexistant.
```
